# YouTube Shorts Factory

End-to-end Shorts automation: story → neural voice → animated video → QA → YouTube upload. No stock footage, no downloaded assets — everything is generated by FFmpeg + Pillow from pure Python.

## What changed from the old pipeline

| Old (broken) | New |
|---|---|
| Static gradient PNGs ("black screen") | Real animated frames — kinetic typography, color themes, text slides, fade/wipe transitions |
| No captions | Burned-in subtitles (white text, semi-transparent box) |
| 10-second fact filler | 60-90 second narrative stories with hook → payoff arc |
| Weak deterministic scripts | Story library (13 stories, daily rotation) |
| No upload path | OAuth refresh-token YouTube Data API v3 resumable upload |
| No QA gate | blackdetect + signal check + duration/size/audio checks (min 60/100) |
| `shorts/make_short.py` missing | Full orchestrator + GitHub Actions workflow |

## Files

- `shorts/stories.py` — 13 story scripts (history, science, motivation, nature, mystery). Daily rotation.
- `shorts/voice.py` — edge-tts neural voice synthesis with gTTS fallback.
- `shorts/render.py` — FFmpeg+Pillow animated video renderer (1080x1920, captions, transitions).
- `shorts/qa.py` — quality gate: duration, dimensions, audio presence, black-frame detection, file size.
- `shorts/make_short.py` — orchestrator CLI. `python shorts/make_short.py` runs everything.
- `.github/workflows/shorts.yml` — daily GitHub Actions cron (9:30 UTC), plus manual `workflow_dispatch`.

## Running locally (dry run — no upload)

1. Install ffmpeg: `sudo apt-get install -y ffmpeg` (Ubuntu) or download from ffmpeg.org (Windows).
2. `pip install edge-tts gtts requests Pillow numpy`
3. `python shorts/make_short.py --dry-run=true`

This builds a video in `shorts/output/` but does NOT upload.

## Running locally (real upload)

You need a Google Cloud project with YouTube Data API v3 enabled and OAuth Desktop credentials:

1. Create OAuth client ID (Desktop app) in Google Cloud Console.
2. Run a local OAuth flow to get a refresh token (scope `https://www.googleapis.com/auth/youtube.upload`).
3. Set `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET`, `YOUTUBE_REFRESH_TOKEN` env vars.
4. `python shorts/make_short.py --dry-run=false`

## GitHub Actions secrets

Set these in repo Settings → Secrets and variables → Actions:

| Secret | Purpose |
|---|---|
| `YOUTUBE_CLIENT_ID` | OAuth client ID |
| `YOUTUBE_CLIENT_SECRET` | OAuth client secret |
| `YOUTUBE_REFRESH_TOKEN` | OAuth refresh token |
| `TELEGRAM_BOT_TOKEN` | Telegram bot token (optional, for notifications) |
| `TELEGRAM_CHAT_ID` | Telegram chat ID (optional) |

## Testing

- `python shorts/make_short.py --list-stories` — list all stories.
- `python shorts/make_short.py --story-id napoleon_height` — build a specific story.
- QA minimum score: 60/100. Videos below that are rejected and NOT uploaded.
